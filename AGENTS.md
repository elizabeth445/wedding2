## Постоянное разрешение на commit и push

- Репозиторий этого проекта: `https://github.com/elizabeth445/wedding2.git`, remote `origin`, рабочая ветка `main`.
- Пользователь заранее разрешил после каждой успешно завершённой задачи на изменение этого сайта выполнять полный цикл: локальные правки, очистка и проверка секретов, `npm run check`, браузерная проверка, понятный коммит и немедленная отправка в `origin/main`. Отдельное подтверждение обычного commit и push не требуется.
- Перед отправкой проверяй `git status`, diff, staged diff, remote и состояние удалённой ветки. Коммить только относящиеся к задаче изменения. Используй локальный Git с настроенной авторизацией или подключённый GitHub-плагин; синхронизируй локальную историю с опубликованным коммитом.
- Проверяй успешность отправки по SHA удалённой ветки и наличию файлов на GitHub. В итоговом сообщении на русском указывай изменения, результаты проверок, статус push и SHA коммита.
- При ошибках проверок, конфликтах, расхождении истории или изменении назначения останови публикацию и сообщи о проблеме. Не используй force push, не удаляй историю и не перезаписывай чужие изменения.
- Разрешение действует только для этого репозитория и задач на изменение сайта. Пустые коммиты не создавай. Деплой и публикация в других репозиториях требуют отдельной команды.
