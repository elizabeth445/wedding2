# Анастасія & Марк — Один день. Ціле життя.

Локальное свадебное приглашение в направлении **Modern Fashion Editorial**: чёрно-белая журнальная композиция, украинские тексты, постановочная фотография, крупная геометричная типографика.

## Запуск

```bash
source ~/.codex/bin/frontend-env.sh # если node/npm отсутствуют в PATH
npm install                       # только при отсутствии node_modules
npm run dev -- --port 5192 --strictPort
```

Открыть [локальное приглашение](http://127.0.0.1:5192/). Для запуска двойным кликом на macOS есть `start.command`.

```bash
npx playwright install webkit # однократно для проверки движка Safari
npm run check                # lint, TypeScript, тесты, production build
```

Playwright использует локальный Chrome, если он установлен, либо доступный Chromium. Путь можно задать через `PLAYWRIGHT_CHROME_PATH`. Тестовый сервер и обычный просмотр используют порт 5192. Готовая сборка — `dist/`.

## Где менять содержание

- `src/config/weddingConfig.ts` — имена, дата с часовым поясом, её подписи, город, время, фотографии, программа, история, дрескод, срок ответа и настройки RSVP. При смене даты обновите также `dateLabel` и `shortDate`.
- `src/data/guests.ts` — нейтральные примеры персонализации без персональных данных: `/?guest=guest-example`, `/?guest=couple-example`, `/?guest=family-example`. Неизвестный ID открывает общее приглашение.
- `src/styles/tokens.css` — шрифты, основная палитра, акценты формы и отступы.
- `src/styles/global.css` — основная композиция и responsive-варианты.
- `src/styles/mobile-layout.css` — центрированная мобильная композиция: равные поля фотографий, заголовки, адрес и ссылки ресторана, кнопки и вертикальный ритм.
- `design.md` — арт-дирекция и причины принятых решений.
- `index.html` — заголовок вкладки, описание и метаданные при замене демонстрационной пары.

Площадка — [Equides Club](https://www.equides.com.ua/), с. Лісники, вул. Вишнева, 36. Название и адрес показаны в блоке дня и секции локации; маршрут ведёт в Google Maps. Фото комплекса хранится локально в `public/images/equides-club.webp`, исходник — `https://www.equides.com.ua/wp-content/uploads/2025/08/back-1.png`. Значения редактируются через `venue` и `photos` в конфигурации.

## Что работает

Журнальная обложка с открытием, пропуском, повтором и Escape; личное приглашение; переключение глав истории; доступный просмотр увеличенной фотографии; таймер с состоянием наступившего дня; программа; скачивание ICS с UTF-8, UTC и переносом строк по RFC 5545; дрескод; адаптивная навигация; RSVP с валидацией, локальным сохранением и редактированием.

RSVP — демонстрация без backend. Данные **остаются только в браузере**, не отправляются паре. Ключ `am-wedding-rsvp-v1:<guest-id>`, схема версионируется и проверяется при чтении. Повреждённая запись игнорируется; при блокировке хранилища появляется понятная ошибка. Для реального сбора ответов требуется отдельно подключить backend.

## Шрифты и изображения

[Tenor Sans](https://github.com/google/fonts/tree/main/ofl/tenorsans) — широкий display-набор; [Arsenal Андрея Шевченко](https://github.com/alexeiva/Arsenal) — узкий текстовый рисунок и выразительный курсив. Локальные TTF и лицензии OFL находятся в `public/fonts/`. Проверка cmap подтвердила ҐґЄєІіЇї и типографический апостроф во всех трёх файлах.

Фотографии пары заменены 22 октября 2026 на четыре отдельных снимка, предоставленных пользователем: `public/images/couple-portrait.jpg` (736×903, обложка и первый экран), `couple-embrace.jpg` (1200×1469, история и фотопросмотр), `couple-fashion.jpg` (736×920, дрескод), `couple-dance.jpg` (736×901, финал). Файлы подготовлены для сайта в JPEG; чёрно-белое отображение задаёт CSS `grayscale(1)`, исходные лица и позы сохранены. Кадры из прежнего коллажа и первоначальные сгенерированные снимки больше не используются в интерфейсе. Фотография Equides Club взята с официального сайта по запросу пользователя. Все изображения загружаются без сторонних CDN.

## Движение и проверка

Использованы существующие React 19, TypeScript, Vite, GSAP и `@gsap/react`. Agentation добавлен как dev-зависимость для визуальных пометок. CSS отвечает за небольшие состояния элементов; GSAP — за открытие обложки, маску истории, появление даты и финальный кадр. `useGSAP` обеспечивает cleanup. `prefers-reduced-motion` отключает анимации и плавную прокрутку, включая смену предпочтения во время открытия. Дополнительного scroll-движка нет.

Фон первого экрана — [Liquid Chrome](https://reactbits.dev/backgrounds/liquid-chrome) из реестра `@react-bits/LiquidChrome-JS-CSS`. Исходник сохранён в `src/components/effects/`, лицензия MIT + Commons Clause — рядом. Дополнительных зависимостей нет. Настройки цвета, скорости и детализации находятся в `ChromeBackground.tsx`, прозрачность и маска — в `editorial-details.css`. Компонент загружается лениво после закрытия обложки. Отрисовка ограничена 30 кадрами/с и 700 тысячами пикселей, приостанавливается вне экрана, в скрытой вкладке и кнопкой паузы; reduced-motion отключает canvas. Без WebGL сохраняется статичная подложка. Тесты `effects.spec.ts` проверяют отрисовку, паузу, возобновление, выход из видимой области и работу без WebGL в Chromium и WebKit.

Тесты находятся в `tests/`. Проверяются интро, фокус, меню, галерея, RSVP, персонализация, недоступное хранилище, календарь, таймер и axe WCAG AA. Responsive-проверки создают скриншоты на **320, 375, 390, 430, 768, 1024 и 1440 px**, измеряют переполнение и проверяют загрузку изображений. Мобильные сценарии выполняются с touch в Chromium и WebKit (профиль iPhone 13). Дополнительно проверяются 12 размеров окна от 320 × 480 до 440 × 800 px, горизонтальная ориентация 667 × 375 и 844 × 390, изменение высоты окна при появлении панелей браузера, отступы safe-area, открытие меню, фото и RSVP. Отдельные сценарии проверяют вложенный мобильный предпросмотр и случай, когда видимая область браузера меньше layout viewport. Это проверка браузерных движков с эмуляцией, а не физических iPhone.

Скриншоты — `output/editorial-<ширина>.png`, `output/cover-<ширина>.png`, `output/phone-cover-<проект>-<ширина>-<высота>.png` и `output/phone-page-<проект>.png`. HTML-отчёт после обычного `npm test` — `playwright-report/`. Итоговые результаты и визуальные исправления — `output/qa-report.md`.

## Визуальные пометки — Agentation

В режиме `npm run dev` справа внизу доступна панель Agentation. Панель работает сразу на обложке, на основной странице и в просмотре фотографий. Нажмите кнопку панели, выберите элемент и добавьте замечание; скопированный контекст можно вставить в чат. Подключение находится в `src/main.tsx` и `src/components/DevelopmentTools.tsx`, загружается лениво только при `import.meta.env.DEV` и исключается из production-сборки. MCP endpoint и вебхуки не настроены: пометки остаются локальными. Панель отображается на экранах от 768 px: Agentation ориентирован на desktop. Ошибка инструмента (например, при блокировке localStorage) изолирована от самого приглашения.

## Подготовка к GitHub и Vercel

Перед передачей проекта: `npm run check`, проверка секретов и просмотр desktop/mobile. После просмотра генерируемые скриншоты, логи и отчёты можно удалить: исходные тесты сохраняются и воспроизводят их. `.gitignore` исключает зависимости, сборку, окружение и временные результаты; `package-lock.json` и необходимые лицензии сохраняются. Репозиторий — https://github.com/elizabeth445/wedding2, ветка `main`. По постоянному разрешению пользователя после успешно проверенных правок этого сайта создаются коммит и push; порядок зафиксирован в проектном AGENTS.md. Деплой выполняется только по отдельной команде.

Для Vercel: установка `npm ci`, сборка `npm run build`, выходная папка `dist`. Секреты для текущего сайта не требуются; RSVP использует только браузерное хранилище.
